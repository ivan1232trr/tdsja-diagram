# TDSJA Diagram Site

This repository hosts a static platform and data atlas. index.html embeds Mermaid, styling and controls. It documents the TDSJA community platform; it does not run the Django application or contain application data.

Keep current implementation and specified target architecture clearly separated.

The website has two connected pages: index.html is the atlas; questionnaire.html collects role-specific data requirements. Shared navigation and atlas-area links connect them. Questionnaire answers remain in the browser or exported files; no central submission service exists.
