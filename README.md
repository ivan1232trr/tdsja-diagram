# TDSJA Platform Atlas

Standalone, offline-capable architecture reference with embedded Mermaid and diagram zoom controls.

## Coolify

Deploy the main branch with the Dockerfile build pack. Container port: 80. No environment variables, database, build command or persistent storage are needed. Set the domain in Coolify.

The atlas distinguishes implemented models from specified target architecture. It contains schema documentation, not database records.

## Connected questionnaire

Open Data Questionnaire from the shared navigation, or follow a data-area link in the atlas. The linked area is preselected. Responses remain local; Save Draft uses browser storage and Export Response downloads JSON. No central collection endpoint exists.
